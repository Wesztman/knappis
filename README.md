# Knappis

A friendly 2D browser game that teaches children (about 3–6 years old) how to
use a hand controller. Walk a little button-creature onto a symbol on the floor
and press the matching button on the pad.

**Status:** planning. See [`docs/ROADMAP.md`](docs/ROADMAP.md).

- [Design](docs/DESIGN.md) · [Roadmap](docs/ROADMAP.md) · [Tech](docs/TECH.md)

## Running (once M0 lands)

```bash
cd game
npm install
npm run dev        # open http://localhost:5173 in your Windows browser
```
